# Linear Algbra Library
### Author: *@ZubinCH*

## About
A computational linear algebra library built in C for simple computer science and engineering projects.

### This program can:
    - Initialise m x n matrices
    - Perform arithmetic (i.e. addition, subtraction, and multiplication) between matrices
    - Compute PA = LU factorisation of matrices
    - More is to be developed
